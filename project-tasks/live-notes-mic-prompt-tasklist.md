# Minutes: Live Notes Pane + Meeting-Detected Prompt — Development Tasks

## Specification Summary
**Source**: `project-specs/live-notes-mic-prompt-setup.md`, version 1.7 (commit dfe201f0). Approved by Todd at the plan gate, 2026-09-22 — the do-nothing row, the RB-1 NEEDS_WORK ceiling, and the WCAG waiver for the meeting-detected card are all confirmed (spec header + section 6).

**Task plan cap**: this run is capped at 7 tasks by requester decision (consolidated from an 18-task plan). Grouping and AC assignment below are fixed by that decision, not re-derived.

**Scope**: REQ-1 (must, independently shippable) then REQ-2 (should, ships whole or is reported unsatisfied). Non-goals from spec section 2 — diarization/speaker names, live transcript editing, pop-out notes window, detection-ladder/`SAME_APP_REMINDER_SECS`/`any_mic_app` changes, queued simultaneous detections, any network call or telemetry, tray/menu-bar and CLI changes, keyboard/VoiceOver card operation, hide-to-tray-on-close, recording-pill Stop latency (already fixed in 5c35f245), pane virtualization, snooze-cancel UI, cross-relaunch pane persistence, coordination with other `live-transcript.jsonl` readers — are out of scope and must not be touched.

**Original requirements** (verbatim):
- REQ-1: "While a recording is active, the main window's recording view shall show every live transcript line and every user note as they arrive, so the whole meeting is visible before processing."
- REQ-2: "When call detection fires and no recording is active, the system shall show a floating always-on-top card at the top-right of the screen offering Record, Not now, and snooze, replacing the OS notification and the in-window banner."

**Technical stack**: Rust workspace — `crates/core` (`minutes-core`), `tauri/src-tauri` (`minutes-app`), Tauri v2, frontend is plain HTML/JS (`tauri/src/index.html`, new page `tauri/src/meeting-detected.html`), no bundler/framework, no new dependencies. i18n via `window.MinutesI18n.t`, English strings are keys, catalogs `tauri/src/locales/zh-CN.js` and `pt-BR.js`. Homebrew rust toolchain: `cargo clippy --all --no-default-features -- -D warnings -A clippy::chunks_exact_to_as_chunks`, `cargo fmt --all -- --check`, `cargo test -p minutes-core --no-default-features`, `cargo test -p minutes-app --bin minutes-app`. Package manager: n/a (no `package.json` changes expected; pure Rust + static HTML/JS). New Playwright harness lives under `tauri/tests-e2e/` with its own `package.json`, committed — not added to `crates/mcp`.

**Target timeline**: not specified in the spec; the 7 tasks run serially, each building on the previous (REQ-1 core → REQ-1 UI → REQ-2 core → REQ-2 backend → REQ-2 card UI → REQ-2 index.html/settings → verification gate).
